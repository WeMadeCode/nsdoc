# 一页 Logo 设计方案

## 1. 品牌关键词

- 一页：从一页开始记录，也代表轻量、克制、专注。
- 个人笔记：私密、长期、可信。
- 参考气质：Notion 的结构感 + 系统备忘录的轻快感。
- 不采用：复杂图形、强科技感、过度卡通、明显模仿 Notion 方块头像或 Apple 备忘录横线纸。

## 2. 推荐方向

Logo 采用“一条横线 + 一张页面”的组合。

- 页面代表“页”。
- 页面中的第一条粗横线代表“一”。
- 下方两条短线代表笔记内容，也让图标不像纯文件图标。
- 折角表示文档和页面，但保持简化，适合作为 iOS App Icon。

## 3. 视觉特征

### 3.1 图形

- 主体是一张圆角页面。
- 顶部右侧有轻微折角。
- 页面中间放置一条醒目的横线，对应产品名中的“一”。
- 下方保留两条短内容线，暗示笔记内容和结构化记录。

### 3.2 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 背景 | `#F7F3EA` | 温和纸张色，接近系统备忘录但更克制 |
| 页面 | `#FFFDF7` | 干净白纸色 |
| 主线条 | `#1F2328` | 近黑墨色，保证小尺寸识别 |
| 辅助绿 | `#7E8F78` | 轻微自然感，避免全黄纸张感 |
| 辅助金 | `#D3B46F` | 与备忘录气质有轻连接 |
| 折角 | `#E7DFD0` | 纸张阴影层次 |

## 5. 使用建议

### 5.1 iOS App Icon

- 使用 `yiyue-app-icon-source.svg` 作为源文件。
- 导出 1024x1024 PNG 用于 App Store 和 Xcode AppIcon。
- 当前可直接使用 `yiyue-app-icon-1024.png`，尺寸为 1024x1024，且不包含 alpha 通道。
- AppIcon 源图背景应铺满整个画布，不预先制作透明圆角；iOS 会在系统层统一裁切圆角。

### 5.2 App 内导航

- 小尺寸场景优先使用单独图标。
- 启动页、官网、文档封面可以使用横版组合。

### 5.3 后续可迭代方向

- 做一个更极简的纯黑白版本，用于深色模式或单色印刷。
- 做一个无文字图标版本，用于 iOS 小尺寸。
- 做一个深色模式版本，背景改为深墨色，页面改为暖白。
